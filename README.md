## Featured projects

### [ritual-job-scorer](https://github.com/vagner67/ritual-job-scorer)
Prototype that follows the **Ritual Chain HTTP precompile (`0x0801`) consumer pattern**: a Solidity contract builds the request, decodes the response and checks a sha256 of the input; a Python (stdlib only) service returns the score.
- 7 pytest + 9 Foundry tests, local end-to-end on anvil, CI green
- Not deployed to a live chain yet (limitations documented in the README)

### [analisador-vagas-ia](https://github.com/vagner67/analisador-vagas-ia)
Job posting analyzer with **RAG**, a **tool-calling agent** and **evals** (Python, FastAPI, SQLite).
- 28 tests, CI on GitHub Actions
- Live demo (offline mode): https://analisador-vagas-ia.vercel.app
